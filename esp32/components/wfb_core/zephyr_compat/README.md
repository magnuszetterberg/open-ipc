Stand-ins for Linux headers that `wfb-ng/src/wifibroadcast.hpp` includes but Zephyr's C library (picolibc) doesn't have, for the radar firmware on the RW612. As with `../esp_compat`, the header uses none of what they declare on Linux; it only needs them to exist, plus `INADDR_ANY` and `SOCK_DGRAM` for two default arguments. Only the Zephyr build puts this directory on the include path, so the submodule stays unedited (R2).
